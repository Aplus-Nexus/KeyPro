# KeyPro samples

## Submit form repeatedly

Open [`submit-form.kpflow`](submit-form.kpflow) in KeyPro to load a complete example:

1. Loop until `Ctrl + Alt + 5` is pressed.
2. Wait two seconds.
3. Type `AAAA`.
4. Try to find the word `Submit` with OCR; fall back to `(640, 420)`.
5. Click the left mouse button.
6. Press `Ctrl + Enter`.

Use **Preview** first. Preview emits the same step log without moving the cursor or typing into the active application.
